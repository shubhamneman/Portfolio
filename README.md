# Shubham Neman React Portfolio
A responsive React + CSS portfolio. It uses Vite and has no component-library dependency.

## Requirements
- Node.js (LTS recommended)
- npm

## Main files
- `src/main.jsx` — React sections, project data, mobile navigation
- `src/styles.css` — layout, colors, responsive styles
- `index.html` — page metadata and fonts
- `package.json` — Vite/React scripts and dependencies
